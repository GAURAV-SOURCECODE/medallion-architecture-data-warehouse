# Project Scope

## In Scope

- SQL Server database initialization
- CRM CSV ingestion
- ERP CSV ingestion
- Bronze raw layer
- Silver cleansing and standardization
- Gold star schema
- Customer/product integration
- Date dimension
- Sales fact
- Data quality checks
- Analytical SQL

## Out of Scope

The current version intentionally does not implement:

- streaming ingestion
- CDC
- incremental ETL
- persistent SCD Type 2
- cloud orchestration
- Spark/Databricks
- real-time dashboards

These can be future extensions rather than claims about the current implementation.
